- browser_open the URL (guess the obvious one: discord.com, youtube.com…).
- Read the page result (text + elements) before clicking. Act on one element at a time and read again.
- Logins, passwords, codes, card numbers: the user types them in the browser panel. Ask them to, then continue.
- If fetch_url is blocked or the page is empty, use the browser instead.
- Downloads, purchases, sending: call the tool; the app asks the user to confirm.
- Report what you saw on the page (titles, values) — copy them, don't paraphrase numbers.
