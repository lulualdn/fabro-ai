title: Researching on the web properly
when: The user asks for current information, comparisons, prices, news or sources
keywords: search, recherche, cherche, web, internet, sources, compare, prix, price, news, actualité, latest
---

1. web_search with a precise query (add the year, the place, the exact product name). Try 2-3 different queries if the first is poor.
2. Open the best 2-4 results (fetch_url; browser_open if the page needs JavaScript or blocks fetch).
3. Take facts only from what the pages say. Note the source of each fact.
4. When sources disagree, say so and give both. When nothing is found, say so.
5. Answer: short summary first, then details, sources as [1], [2] with the page titles.

Pitfalls
- Search snippets are partial: read the page before quoting a number.
- Dates: check the page date; prefer recent sources for prices and versions.
- Never fill gaps from memory for facts that change (prices, versions, schedules).
