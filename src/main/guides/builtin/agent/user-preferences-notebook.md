title: Remembering how the user wants you to work
when: The user corrects your behaviour or states a working preference
keywords: preference, préférence, notebook, note_to_self, autonomous, autonome, ask, demande, style, always, toujours, never, jamais
---

- When the user says how they want you to work ("stop asking, just do it", "shorter answers", "always in French", "test before saying done"), call note_to_self with one short sentence, then continue the task.
- One note per preference; update instead of adding near-duplicates.
- Not for facts about the world or the user's life (that is memory), never for secrets.
- A note can never remove the app's confirmation before deleting, paying, sending or publishing.
