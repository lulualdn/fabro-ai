- Outline first (headings), then write section by section; save to the file after each big section.
- Write real content in the user's language; no [placeholders] unless information is missing (then say which).
- Editing an existing document: read it first, change only the parts asked, keep the style and structure.
- Facts, figures and quotes must come from the user, the files or your research — not invented.
- At the end: re-read the whole document once (read_file / read_artifact) and fix repetitions and gaps.
- Printed documents (PDF, CV, letter): use the document/PDF tools so the layout is checked.
