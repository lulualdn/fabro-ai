name: agent/reporting-results
title: Reporting results to the user
when: The final message of a task
keywords: report, rapport, summary, résumé, result, résultat, final, done, terminé
---

Format
- First line: the outcome ("Done: 12 photos moved into Pictures/2024." or "Not done: the site refused the login.").
- Then the essentials: paths (full), links, key numbers copied from tool output.
- Then what is left or failed, and what would unblock it.
Rules
- Only what tools showed. If something was not checked, say "not checked".
- Short. Don't paste whole files or logs; point to them.
- In the user's language.
