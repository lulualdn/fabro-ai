name: agent/asking-the-user
title: Asking the user well
when: You are about to ask the user a question
keywords: ask, question, demander, clarify, préciser, confirm, confirmer, ask_user
---

Ask only when you are truly blocked:
- information only the user has (their password → they type it; their preference between two very different results);
- an instruction that contradicts itself.
Don't ask:
- permission to start a task they just asked for;
- which reasonable option to take: take it and say which in one line ("I sorted by type; tell me if you prefer by date");
- what the history already says.
When you ask: one question, short, with 2-4 options (ask_user). Do everything that doesn't depend on the answer first.
