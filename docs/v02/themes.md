# Themes (v0.2)

Files: `themes-core.js` (pure: colour maths, manifest schema, sanitiser, token derivation, CSS compile; also runs in
node), `themes-data.js` (built-ins), `themes.js` (runtime: apply, store, import/export), `themes-ui.js` (gallery),
`themes-boot.js` (applies the cached theme before first paint), `keys.js` (keyboard layer), `styles/themes/*.css`.

## Manifest (`.fabrotheme.json`)

```
{ v:1, id, name:'x'|{en,fr}, author, base:'light'|'dark'|'both', desc?,
  palette:{ light?:{bg,panel,elev,text,accent,…}, dark?:{…} },   // a few seeds, the rest is derived
  tokens:{ all?:{…}, light?:{…}, dark?:{…} },                    // whitelisted token names, typed and range-checked
  fonts:{ ui?, read?, display?, mono? },                         // system font stacks only
  texture:{ kind:'grain'|'grid'|'scanlines'|'dots'|'none', opacity, size?, layer:'under'|'over' },
  motion:'default'|'calm'|'steps'|'snap'|'none', layout:''|'cli' }
```

An imported theme is untrusted data: no CSS, no script, no `url()`, no remote font, no `--logo`; unknown keys and
out-of-range values are dropped; size capped. Textures are generated by Fabro from the fixed list. Derived colours
are pushed until every text pair passes WCAG AA (body text 7:1, other text 4.5:1, accent/focus 3:1).

## Built-ins

Fabro (the default look, `tokens.css`, untouched), Marginalia, Graphite, Contraste élevé, Marée, Plan (Blueprint),
CLI, Phosphore (dark only). `node scripts/themes-test.js` checks every pair of every theme in both modes, the
sanitiser against hostile files, and the compiled CSS. The default Fabro light look is reported but not enforced:
white on coral is 4.42:1 and the comment colour in code is 3.23:1 (identity colours, left as they are).

## CLI theme and keyboard

Monospace, no radius, 1 px rules, `you ›` / `fabro ›`, tool steps as log lines, block cursor, status line
(model · context · tok/s · account), dry motion. Keys (on in the CLI theme, or "Keyboard navigation" on): `j`/`k`,
`Enter`/`l`, `h`, `g g`/`G`, `[`/`]`, `/`, `i`, `?` (cheat sheet), `Esc`, `Ctrl+N`, `Ctrl+K` / `Ctrl+Shift+P`
(palette; Ctrl+Shift+P in every theme). Slash commands in the composer: `/new /clear /theme [name] /model /settings
/voice /keys`. Never a key while typing in a field (only the documented chords). `node scripts/keys-e2e.js`.

## Screens

`node scripts/themes-shots.js --out <dir>` (welcome, chat, settings, artifact panel, palette, gallery; light/dark;
phone width for CLI). The gallery opens from the palette or `/theme`; Settings will mount `Themes.renderSection(el)`.
