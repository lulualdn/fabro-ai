# Example mods (Fabro mod API v1)

Copy a folder into Fabro's mods folder (Settings → Mods → Install or remove a mod → Open the folder), then turn it on.

- `daily-card`: a request shown above the chat, and a `/idee` command.
- `paper-chat`: a new look for the chat (CSS and a message hook).
- `flashcards`: `/flashcards` turns the conversation into cards to review above the chat.

Documentation: https://fabro.ufstudios.eu/docs-mods.html
