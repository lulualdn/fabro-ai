## Fabro ne démarre pas
Relance-le une fois. S’il plante encore au démarrage, il redémarre sans les mods la fois suivante. Si ça ne suffit pas, réinstalle par-dessus : tes réglages et tes conversations sont gardés.

## Les réponses sont lentes
- Ouvre Réglages → Modèles → **Mesurer à nouveau** : Fabro choisit le moteur le plus rapide sur ta machine.
- Ferme les jeux ou applis qui prennent la carte graphique.
- Prends un modèle plus petit pour le quotidien, et le bouton « Demander au gros modèle » quand il faut.

## Une mise à jour a échoué
Rien n’est perdu : ta version précédente est intacte. Clique **Réessayer**. Si ça échoue encore, télécharge l’installateur depuis la [page d’accueil](index.html#download) et lance-le.

## Fabro Anywhere ne trouve pas mon PC
- Fabro doit être ouvert sur le PC, avec Fabro Anywhere activé.
- Certains réseaux (entreprise, école) bloquent les relais. Essaie en 4G.
- En dernier recours, oublie le PC dans Fabro Anywhere et relie-le à nouveau.

## Ma clé API est refusée
Vérifie le modèle demandé : chaque fournisseur a ses propres noms. Après avoir tapé la clé, la liste des modèles du fournisseur apparaît dans le champ « Modèle ».

## Le micro ne marche pas
Autorise le micro pour ce site dans les réglages du navigateur, puis recharge la page.

## Désinstaller
Windows : Paramètres → Applications → Fabro. macOS : glisse Fabro dans la corbeille. Tes données restent dans le dossier Fabro de ton profil ; supprime-le si tu veux tout effacer.
