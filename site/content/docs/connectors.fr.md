# Connecteurs (MCP)

Un connecteur donne à Fabro l’accès à un service : GitHub, Google Drive, Notion, une base de données, ta maison connectée… Fabro utilise le protocole MCP.

## Ajouter un connecteur
Réglages → Connecteurs. Cherche le service, puis **Ajouter**. Fabro télécharge ce qu’il faut (Node, Python ou le programme du serveur) : rien à installer à la main. Si le service demande une connexion, une fenêtre s’ouvre.

## Fichier .mcpb
Un fichier `.mcpb` est un connecteur emballé. Dépose-le dans Réglages → Connecteurs. Fabro affiche ce qu’il pourra faire avant de l’activer.

## Serveur à une adresse
Colle l’adresse d’un serveur MCP distant dans la même page. Les jetons restent dans Fabro.

## Retirer
Chaque connecteur a un bouton **Retirer**. Ses fichiers sont supprimés, tes conversations restent.
