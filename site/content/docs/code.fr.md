# Fabro Code

Fabro Code est le mode pour programmer. Il lit ton projet, modifie les fichiers, lance les tests et la ligne de commande, et garde des points de retour.

## Dans l’app
Ouvre **Fabro Code** dans la barre latérale et choisis un dossier. Chaque modification apparaît en différence, à accepter ou annuler.

## Dans le terminal
L’installateur ajoute la commande `fabro`. Dans un dossier de projet :

```
fabro code
```

C’est la même interface en mode texte, avec le même moteur, les mêmes sessions et les mêmes autorisations que dans l’app. La mascotte s’affiche en couleurs ANSI, ou sans couleur si ton terminal n’en a pas.

## Autorisations
Lire les fichiers du projet ne demande rien. Écrire et lancer des commandes demandent ton accord la première fois, par projet.
