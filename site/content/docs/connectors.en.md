# Connectors (MCP)

A connector gives Fabro access to a service: GitHub, Google Drive, Notion, a database, your smart home… Fabro uses the MCP protocol.

## Add a connector
Settings → Connectors. Search for the service, then **Add**. Fabro downloads what it needs (Node, Python or the server itself): nothing to install by hand. If the service needs a sign-in, a window opens.

## .mcpb file
A `.mcpb` file is a packaged connector. Drop it on Settings → Connectors. Fabro shows what it will be able to do before turning it on.

## Server at an address
Paste the address of a remote MCP server on the same page. Tokens stay in Fabro.

## Remove
Each connector has a **Remove** button. Its files are deleted, your conversations stay.
